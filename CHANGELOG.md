# Changelog

## 1.0.0.0 — October 2026

First release.

- Words or free text (stopwords in en, es, pt, fr, de, it; automatic language detection; minimum length; exclusion list; two-word phrases). In free text, Color value is averaged over the rows that contain each word.
- Shapes: rectangle, circle, ellipse, diamond, triangle, hexagon, 42 icons, text, image from the model; silhouette, outline and dense fill.
- 32 palettes (18 colour-blind safe), theme colours, single colour with fx, gradients by size or measure, sentiment.
- Style templates: Clean, Bold, Editorial, Monochrome, Poster.
- Orientation: horizontal, vertical, mixed, custom angles; jitter and fixed seed.
- Cross-filtering, multi-select, highlighting, bookmarks, drilldown, tooltips and report page tooltips, context menu, on-object formatting, fetchMoreData past 30,000 rows, warning icon.
- Keyboard navigation, ARIA labels, high contrast. Format pane in 12 languages.
