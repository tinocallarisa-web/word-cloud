# Word Cloud by TCViz

A free word cloud for Power BI — every feature, no licence, no watermark.

- **Words or free text.** A column of words, or survey comments, tickets and reviews that the visual splits into words, with stopwords in 6 languages and automatic language detection.
- **Shapes.** Rectangle, circle, ellipse, diamond, triangle, hexagon, 42 icons, your own text, or an image stored in the model.
- **Colour.** 32 palettes (17 colour-blind safe), theme colours, fx conditional formatting, gradients, and sentiment colouring centred on zero.
- **Power BI.** Cross-filtering, highlighting, bookmarks, drilldown, report page tooltips, format on the canvas, keyboard navigation, high contrast, Format pane in 12 languages.
- **Private.** No network access: nothing leaves your report.

## Build

```
npm install
node build-test.js      # test package with a _test GUID, alongside the AppSource version
```

Requires Node 18+ and powerbi-visuals-tools 7.
